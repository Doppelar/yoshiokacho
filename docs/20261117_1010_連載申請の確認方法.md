# 連載申請の確認方法

2026-11-17確認。申請内容・設定・DBは変更していない。

## 現在使える確認方法

1. [本番Supabase Table Editor](https://supabase.com/dashboard/project/oodylfqaiuxathqekjve/editor) に管理者としてログインする。
2. public スキーマの `local_edition_applications` を開く。
3. `status` が `pending` の行に絞る。受付順は `created_at` で確認する。
4. `municipality_name`（自治体）、`contact_name`（担当者）、`email`（連絡先）、`site_url`、`introduction` を確認する。

確認時点の未審査は7件。個人情報のある行や画面は公開しない。
