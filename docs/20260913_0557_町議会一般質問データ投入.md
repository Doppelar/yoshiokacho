# 吉岡町議会 一般質問データの投入について

## 背景

本フォーク(みらい議会＠吉岡町)は、既存の `bills`(法案)テーブルを流用して
吉岡町議会の「定例会 一般質問」を掲載する。既存の `bills` は国会の法案審議
(衆議院/参議院、成立/否決など)を前提にしたスキーマだが、以下の方針で最小
工数で流用する(スキーマ変更・新規テーブルは作らない)。

## データモデルの割り当て

| 概念 | 割り当て |
|---|---|
| 1レコード | 1議員 = 1レコード(その議員の一般質問項目をすべて本文に含める) |
| `bills.originating_house` | 固定値 `"HR"`。町議会には衆参の区別が無いため技術的な必須値として使うのみ。UI側の院ラベルは表示しない運用にした |
| `bills.status` | 固定値 `"enacted"`。一般質問はすでに実施・答弁済みのため「完了」を表す状態として使う |
| `bills.status_note` | `"答弁済み"` |
| `bills.submitted_date` | 定例会の開催日 |
| `bill_contents` | `normal` / `hard` の両難易度に同一内容を登録(AIによる易化リライトは今回未実施) |

## UI文言の調整(表示文言のみ)

このフォークのデータは今後すべて町議会の一般質問になる想定のため、以下の
表示文言だけを町議会向けに調整した。内部のenum値・カラム名・テーブル名は
`bills` 系のまま変更していない。

- `web/src/features/bills/client/components/bill-detail/bill-status-progress.tsx`
  - 見出し「審議のステータス」→「質問の状況」
  - ステップラベル「法案提出/衆議院審議/参議院審議/法案成立」→
    「質問通告/本会議質問/執行部答弁/対応完了」
- ステータスラベルの `enacted` → 「成立」「法案成立」を「実施済み」に統一
  (`getBillStatusLabel` / `getCardStatusLabel` / `BILL_STATUS_GROUP_LABELS` /
  `CompactBillCard` の日付サフィックス「成立」→「実施」/
  `BillListWithStatusFilter` のフィルタラベル)

## データ投入の仕組み(継続運用向け)

定例会(年4回想定)ごとに、吉岡町議会ホームページの「一般質問一覧」ページを
そのままコピー&ペーストしたテキストファイルから、`bills` / `bill_contents`
へ追加投入できるスクリプトを用意した。既存データを削除しない追加投入。

- パーサー(純粋関数、テスト付き):
  `packages/seed/general-questions/parse-general-questions.ts`
- 投入スクリプト(DB書き込み):
  `packages/seed/general-questions/import-general-questions.ts`
- サンプル入力データ:
  `packages/seed/general-questions/data/2026-reiwa8-3rd-teireikai.txt`
  (令和8年第3回定例会 令和8年9月4日)

### 想定入力フォーマット

```
令和8年第3回定例会　令和8年9月4日（金）　　本会議 一般質問

大井　俊一　議員
1.吉岡町に生息する外来種問題と在来種問題についての対応は
(1)日本国内における外来種問題の現状をどのように捉えているのか
(2)吉岡町内に生息する外来種と問題となる在来種の生息状況と問題の現状は
2.コロナ後の吉岡町における産業振興策について
(1)コロナ後の吉岡町における経済活動状況をどのように判断しているか	映像を再生します

飯島　衛　議員
...
```

- 議員ブロックは空行区切り
- 各ブロックの1行目は「氏名(全角スペース区切り)　議員」
- 大項目「N.見出し」、小項目「(N)本文」
- 行末のタブ区切りリンク文言(「映像を再生します」等)は自動的に除去される

### 実行方法

```bash
pnpm --filter @mirai-gikai/seed seed:general-questions -- \
  general-questions/data/2026-reiwa8-3rd-teireikai.txt 2026-09-04
```

第1引数: 入力テキストファイルのパス、第2引数: 定例会開催日(YYYY-MM-DD)。

ローカルSupabase(`npx supabase start`)が起動している必要がある
(`.env` の `SUPABASE_URL` / `SUPABASE_SECRET_KEY` を参照する)。

### テスト

```bash
pnpm --filter @mirai-gikai/seed test
```

## 未対応・今後の検討事項

- **画面表示文言は最小限修正にとどめており、「法案」等の言葉は全面的には
  置き換えていない**(例: ナビゲーションの「法案一覧」、AIチャットのプロン
  プト文言などは国会法案を前提にした文言のまま)。表記を全面的に町議会向け
  に統一する場合は別途対応が必要。
- 議員マスタ(会派・当選回数等)は作っていない。表記揺れ(全角/半角スペース
  等)がある場合はパーサーの正規表現の調整が必要になる可能性がある。
- 答弁内容(議事録本文)は含まれていない。今回投入したのは「質問項目一覧」
  のみで、実際の答弁内容は別途入力が必要。
- AIチャット機能・インタビュー機能など、bills に紐づく他機能への影響は
  未検証(投入したデータでも動作はするはずだが、想定コンテンツが国会法案の
  ため、AIプロンプトの文言が町議会の内容と噛み合わない可能性がある)。
