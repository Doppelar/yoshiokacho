# 全国一覧の注意書き・検索除外・MUSEマーク

## 要望と確定した表示方針

全国一覧に、MUSEやバイブコーディングで作成されたサイトには不確かな情報・誤りが含まれる場合があることを明記する。共有はみらいのサポーターとその知人程度にとどめ、広い拡散を控えるよう依頼する。

作成方法のマークは、ユーザーの回答「MUSEのみマーク記載」に従う。MUSE以外をバイブコーディング製と推測して表示しない。

## 実装範囲

- 共通の `DirectoryNotice` を全国地図と全26都道府県の市町村地図へ表示。
- 一覧のMUSEリンクに `MUSE` バッジを表示。読み上げでも「MUSEで作成」と分かる。
- MUSE判定はHTTP/HTTPSの `muse.ai` と `www.muse.ai` のホスト名に限定。別ホスト・偽装URL・内部リンクは対象外。
- 既存の「暫定公開（運営者募集中）」は運営状態の別表示として保持。
- `isNationalEditionPage` の対象（/japanとその配下、都道府県地図、/updates）に、middlewareで `X-Robots-Tag: noindex, nofollow` を設定。
- /japan配下はmetadataにもnoindex/nofollowを設定。
- sitemapは従来から全国一覧・県別地図を掲載していないため変更しない。
- robots.txtでクロールを遮断しない。検索エンジンがnoindexを読み取れる状態を保つ。[Googleの公式説明](https://developers.google.com/search/docs/crawling-indexing/block-indexing)を参照。

## 検証

MUSE URL判定・マーク・既存の暫定公開や地図・ページ判定を含む関連64テスト、web型チェック、対象Biomeを確認する。

ローカル実HTTPで/japan・/tochigi・/gunma・/nagano・/updatesの検索除外、/termsと/api/deploymentの従来応答保持を確認。全国・県ページで注意書きが1つだけ表示されることも確認する。

ブラウザで栃木の4MUSEリンク、群馬の32MUSEリンクと非MUSEの3内部リンクを照合し、非MUSEにマークが付かないことと、スマートフォン表示を確認する。画面はworktreeの `notice-japan-mobile.png`、`muse-tochigi-mobile.png`、`notice-gunma-mobile.png` に保存。最新CI・Preview・公開承認・本番SHAと確認結果はPR本文を参照する。

## 制約と公開時の確認

検索除外は閲覧制限ではない。URLを知っている人は引き続き閲覧できる。MUSE等の外部サイトの検索設定を、このリポジトリから変更することはできない。既に検索に載っている場合、検索エンジンがnoindexを再取得するまで掲載が残る可能性がある。

認証・DB・環境変数・workflow・Vercel設定は変更していない。ページのリンクや掲載データは保持する。CIとPreview成功後、具体的なPRへの本番公開承認を得る。公開後は/api/deploymentのSHA・projectId、検索除外ヘッダー、注意書き・MUSEマークと既存リンク、Verify productionを確認する。
