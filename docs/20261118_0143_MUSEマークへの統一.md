# MUSEマークへの統一

ユーザーはMUSEマークを残し、ラッパのアイコンを外し、凡例もMUSEの表示についての説明にすることを希望。

- 地図・市町村一覧・凡例・島根県ポータルからラッパを除去する。
- 暫定公開の区分は読み上げ向けの補足として維持し、表示するマークはMUSEに統一する。
- 凡例は「MUSEの表示はMUSEで作成されたサイトへのリンク」と説明し、暫定版の有志作成・内容を保証しない旨・継続的な運営の申請案内を保持する。
- MUSEの表示と暫定公開の区分は同一ではない。MUSEのサイトすべてを暫定公開と断定しない。
- 島根県の一覧ポータルもMUSEバッジに揃える。URLは変更しない。
- 検索除外、MUSE以外を無印にする方針、既存リンク・データ・暫定版対象県を保持する。

関連テスト・型チェック・Biome、実HTTPの群馬・長野・島根・栃木でラッパなし/MUSE維持/検索除外維持を確認する。スマートフォン画面と最新CI・Preview・公開承認状況・本番SHAはこのブランチ `fix/muse-only-mark` のPR本文を参照する。

DB・認証・環境変数・workflow・Vercel設定の変更なし。PRへの明示承認後に本番公開し、全ページのアイコン除去とMUSE表示、公開後チェックを確認する。
