# 全国地図のURL共有プレビュー修正

## 問題と対応

全国地図 `/japan` のページタイトルは個別指定されていたが、Open Graph・Twitterの共有設定はルートの吉岡町用設定を継承していた。画像 `/ogp.jpg` にも「＠吉岡町」の表記があり、実際の本番共有タグの画像URLはlocalhostになっていた。

`web/src/app/(main)/japan/layout.tsx` に、共有時のタイトル・サイト名「みらい議会 地方版」、全国の市町村向けの説明、専用画像を設定した。画像の絶対URLはこのフォークの本番URLを使う。このレイアウトは `/japan` 配下にのみ適用される。ページ上のヘッダー名・都道府県ページ・吉岡町のトップや議案情報は今回の変更対象外。

- PNG: `web/public/img/local-edition-ogp.png`（1200×630）
- 編集元: `web/public/img/local-edition-ogp.svg`
- 既存の `web/public/img/ogp-logo.png` と既存Miraiカラーを使用。
- 外部フォント取得や実行時の画像生成は不要。
- 本番URLを変更した場合は、このレイアウトのmetadataBaseも更新する。

## 画像の再生成

agent-browserで1200×630のビューポートを指定し、SVGファイルを直接開いてPNGへスクリーンショットを書き出す。PNGは等倍で保存し、日本語の表示と端の欠けを目視確認する。フォントはNoto Sans JP・游ゴシック・メイリオの順で使用する。

## 検証と公開

ローカルの `/japan` にTwitterbotのUser-Agentでアクセスし、og:title・og:site_name・twitter:title、説明、画像URLが地方版用に置き換わっていることを確認する。画像はHTTP200・image/png・1200×630であることを確認する。`/terms` は従来の共有設定を維持することも確認する。

CI・Preview成功後、PRへの明示承認を得てproductionへマージする。最新のPR状態・本番SHA・公開後の確認結果はPR本文を参照する。SNSの既存プレビューにはサービス側のキャッシュが残る可能性があるため、本番HTMLの共有タグと画像を先に確認し、新しくURLを送った結果と分けて確認する。

DB・認証・環境変数・workflow・Vercel設定の変更なし。以前のworktreeとメインリポジトリの未コミット変更は触れない。
